OpenDownloader.

Save a video from a web page to your computer

Paste a link and it is saved to your computer. The download runs in this tab, on your machine — nothing is uploaded, an interrupted file picks up where it stopped, and every finished one is checked against a SHA-256 digest read back off disk.

A video page on YouTube, Bilibili, Vimeo, Dailymotion, Twitch or X — or a direct file link, an .m3u8 playlist, a magnet link, or a Mega, Quark or eD2k share. See everything it knows

The browser extension does more

This page can only download links you paste, because a web page is not allowed to see what another site loads. The extension watches the page you are on and offers what it finds, one site at a time and only where you turn it on. It is the same engine and it is equally free.

Get the extension

Chrome, Edge and Firefox builds are attached to the latest release. Download the one for your browser, unzip it, and load it from the browser's own extensions page — it is not in the stores yet, so there is nothing to search for.

Sites it knows

Any direct link to a media file or a playlist works anywhere. These have extractors of their own, so pasting a page link is enough — and the ones marked need the extension, because a web page is not allowed to read another site's page. The last few are link kinds rather than websites; those marked need a helper running on your own machine. Services whose media is DRM-protected are refused, in code, and so is any encrypted stream anywhere.

OpenDownloader is open source under MIT or Apache-2.0. Read the code. Nothing here is metered, and there is no paid tier to upgrade to.

Some servers refuse to be read by a web page. If a download fails for that reason, you can run the relay from the repository on your own machine and point this page at it in Settings — or use the extension, which never has that problem.
