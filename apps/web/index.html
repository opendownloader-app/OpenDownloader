OpenDownloader

Save a video from a web page to your computer

Paste the link to a video, audio file or stream and it is saved to your computer. Interrupted downloads pick up where they stopped, and every finished file is checked with a SHA-256 digest read back off disk.

Every feature is free, there is no account, and nothing is uploaded: the download runs in this tab, on your machine.

A direct link to a file or an .m3u8 playlist, or a video page on a supported platform. Services whose media is DRM-protected are refused, in code, and so is any encrypted stream anywhere.

What people use this for

Saving a recorded class

Keep a lecture or training video for offline study, with the download resuming if the connection drops.

Keeping a meeting recording

Save a call recording to your own disk before the link expires, and confirm the copy is intact.

Turning a video into audio

Pull the soundtrack out of a video as an M4A or MP3 to listen to on the way somewhere.

Rescuing a broken stream

Join loose .ts segments back into one playable MP4 when a download stopped part way.

The browser extension does more

This page can only download links you paste, because a web page is not allowed to see what another site loads. The extension watches the page you are on and offers what it finds, one site at a time and only where you turn it on. It is the same engine and it is equally free.

OpenDownloader is open source under MIT or Apache-2.0. Read the code. Nothing here is metered, and there is no paid tier to upgrade to.

Some servers refuse to be read by a web page. If a download fails for that reason, you can run the relay from the repository on your own machine and point this page at it in Settings — or use the extension, which never has that problem.
